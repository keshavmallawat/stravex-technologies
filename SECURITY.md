# Security Policy

## Supported Versions

This project is currently provided as a portfolio showcase. As such, only the latest tagged version is actively maintained.

| Version | Supported          |
| ------- | ------------------ |
| v2.0.x  | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

Security is a top priority for Stravex Technologies. Even though this repository is primarily a portfolio piece, we treat security disclosures with enterprise-grade professionalism.

If you discover a security vulnerability within this project, please DO NOT create a public GitHub issue. Instead, disclose it privately by sending an email to:

**mallawatkeshav@gmail.com**

Please include the following in your email:
1. A clear description of the vulnerability.
2. Steps to reproduce the issue.
3. The potential impact.
4. (Optional) Any suggested mitigations.

We will acknowledge receipt of your vulnerability report within 48 hours and strive to resolve critical issues promptly.
