# Contributing to Stravex Technologies CMS

Thank you for your interest in the Stravex Technologies CMS 2.0 repository!

This repository currently serves as a **professional portfolio project** and operates under an **All Rights Reserved** license. As a result, we are not actively accepting open-source pull requests for new features.

However, if you are a recruiter, client, or engineering reviewer, we welcome you to:
1. **Explore the Architecture**: Review our codebase, Server Actions, Prisma schemas, and Graphify integrations.
2. **Review the QA Process**: Read the extensive reports in `docs/reports/` detailing our QA and performance audits.
3. **Run Locally**: Clone the repository and follow the setup instructions in the `README.md` to see the CMS in action.
